# Python en 7 Días - De Cero a Experto con Proyectos y Retos

Aprende Python desde Cero con ejercicios y Proyectos reales. POO, Conexion a BD, Tkinter, Flask, Mysql y mucho más.

- Aprenderás Python desde conceptos básicos como Variables, Operadores, Sentencias de Decision if else elif, Ciclos for y while, Funciones, POO y mas.
- Hasta conceptos avanzados como Manejo de Archivos, Conexión a Base de Datos con MySql
- Creación de una interface gráfica con Tkinter con Conexión a Base de Datos con MySql
- Creación de una aplicación Web usando Flask, HTML y Bootstrap
